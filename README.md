# Ragdoll City

A browser physics game: active-ragdoll dummies, a small city, an M4A1, Glock 17 and 12-gauge, and a motorcycle.
Built with [three.js](https://threejs.org) 0.160 and [cannon-es](https://github.com/pmndrs/cannon-es) 0.20 (both loaded from jsDelivr).

**Play:** open `index.html` through a web server (GitHub Pages works). Opening the file straight from disk won't load the models.
